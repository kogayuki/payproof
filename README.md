# PayProof

**支払い実績が、あなたの信用になる。**

開示リワード型の電力与信プラットフォーム（MVP / デモ）。**2026-08-16 デモデーに向けて仕上げ中。**

- 本番URL: https://payproof-yukis-projects-e1815ffa.vercel.app （`payproof.vercel.app` は別人のプロジェクトなので注意）
- デプロイ: `main` に push すると Vercel が**本番へ自動デプロイ**します（下記「開発ルール」参照）

## 誰の・どんな課題を・どう解くのか

クレジットカード業界（CIC）や通信業界（TCA不払者情報交換）と違い、電力業界には**未払い情報を共有する仕組みがなく、契約時の審査も行われません**（審査コストが低単価商材に見合わないため）。未払いのまま他社へ乗り換えるユーザーを契約時に見分けられず、貸倒・督促コストは全ユーザーの電気料金に転嫁されています。一方、真面目に払ってきた人には**実績を証明する手段がない**。

> **開示にリワード（割引）を払うことで、開示しない選択が自動的にリスクシグナルになる（逆選択の解消）。**

- ユーザーは契約時に、前の電力会社での支払い履歴（**相互参照**・本人同意起点）の開示を**任意で**選択できる
- 検証結果に応じて5段階ティア（A=電気料金3%割引 / B=1%割引 / C=標準 / 実績構築中=ウェルカム特典 / 非開示=標準条件・割引なし）
- 人を善良/悪質と評価しない。**事業者に渡るのはティアのみ**で、生の延滞データは本人だけが見る

## デモストーリー（30秒）

引っ越してきたユーザーが、前の電力会社での支払い実績を**ワンタップで開示**し、その場で**電気料金3%割引が適用**。電力会社が信用証明を照会するたび、ユーザーにマイクロリワードが即時着金する（表示はJPYC建て・1 JPYC/照会。レールはx402 / Base Sepolia、デモはsimulated）。

## セットアップ

```bash
git clone https://github.com/kogayuki/payproof && cd payproof
npm install
npm run dev
```

**環境変数なしで全機能が動きます**（デモ用フォールバック内蔵）。

| 環境変数 | 用途 | 未設定時の挙動 |
|---|---|---|
| `CREDENTIAL_SECRET` | JWS署名の秘密鍵 | デモ用フォールバック鍵で署名 |
| `X402_PAY_TO_ADDRESS` | x402の受取アドレス（Base Sepolia） | 照会APIは非課金で動作 |
| `X402_BUYER_PRIVATE_KEY` | 照会デモの買い手ウォレット秘密鍵 | 支払いをsimulatedに降格 |

## 画面・コード構成

| パス | 内容 |
|---|---|
| `/` | LP |
| `/apply` | ユーザー開示フロー（申込→開示同意→前電力会社へのモック照会→ティア判定・割引結果） |

| `lib/x402.ts` | x402設定（eip155:84532=Base Sepolia、facilitator.x402.org、還元率30%、表示はJPYC建て） |

## 開発ルール（8/16まで）

1. **`main` へ直接pushしない**（本番に即デプロイされるため）。ブランチを切ってPRを出す → Vercelが**Preview URL**を自動発行するので、そこで動作確認
2. **スコープ凍結中**: 新機能は追加しない。バグ修正・UI磨き込みのみ
3. **作らないもの**（意図的にスコープ外）: 実銀行API連携 / ZKP / 本人確認 / スコアリング精緻化 / モバイル対応

## 実装上の注意（ハマりどころ）

- **Next.jsはトレーニングデータより新しい**。`AGENTS.md` 参照 — API・規約が変わっている可能性があるため、`node_modules/next/dist/docs/` のガイドを確認してから書くこと
- **shadcn/uiはBase UI版**: `asChild` は使えない。`render` プロップを使う
- **x402はv2**（`@x402/next` 等）。v1の `x402-next` パッケージはdeprecated — 検索結果やLLMの提案がv1のことがあるので注意
- UIは日本語・白基調ライトテーマ（ネイビーブルーアクセント、日本のSaaS風）。デモ聴衆はWeb3+一般の混合
